# Link Organizer API

REST API for saving web links and filing them in nested categories.

- **Base URL:** `http://127.0.0.1:3000`. Set by `HOST` and `PORT` in the config file.
- **Format:** JSON in, JSON out. Send `Content-Type: application/json` with every request that has a body.
- **Auth:** none. The MVP assumes one local user.
- **Contract source:** `../link-organizer-ui/mock-data/`. This document describes what the server actually does.

The examples use `curl` and these shell variables:

```sh
BASE=http://127.0.0.1:3000
FOOD=6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01      # a category id
LINK=9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02      # a link id
```

---

## Conventions

| Topic | Rule |
| --- | --- |
| Success body | One item: `{ "data": ... }`. A list adds `"meta": { "total": n }`. |
| Error body | `{ "error": { "code", "message", "details"? } }`. You can show `message` to users as-is. |
| Ids | UUIDs, generated by the server. An id in the path that is not a UUID returns `404 NOT_FOUND`. |
| Timestamps | ISO 8601 UTC with milliseconds, e.g. `2026-11-20T18:10:00.000Z`. |
| Optional values | Always present in responses as `null`, never left out. |
| `PATCH` | Partial update. Send only the fields that change. A field that is left out stays as it is; a field sent as `null` is cleared. |
| Strings | `title`, `url`, `description` and `name` are trimmed. An empty `description` is stored as `null`. |
| Rich text | A link's `notes` is an HTML fragment. The server sanitizes it before storing; see [Notes](#notes). |
| Unknown fields | Ignored. |
| Caching | API responses use `Cache-Control: no-store` and do not support ETag revalidation. |

## Resources

### Category

A folder for links. Categories nest to any depth: a category with a `parentId` is a subcategory of that parent.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | uuid | Read-only. |
| `name` | string | Required, 1–80 characters. Two categories with the same parent can't share a name; the check ignores case. |
| `parentId` | uuid \| null | `null` means a top-level category. Must reference an existing category. |
| `createdAt` | date-time | Read-only. |
| `updatedAt` | date-time | Read-only. |

```json
{
  "id": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
  "name": "Italian",
  "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01",
  "createdAt": "2026-11-01T15:01:00.000Z",
  "updatedAt": "2026-11-01T15:01:00.000Z"
}
```

### Link

A saved web link. A link can act as a *parent* link (a site's home page, say), with related sub-links such as its Careers and About pages kept in `notes`.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | uuid | Read-only. |
| `title` | string | Required, 1–200 characters. |
| `url` | string | Required. Must be an absolute `http://` or `https://` URL of at most 2048 characters. No two links can have the same URL. |
| `description` | string \| null | Up to 2000 characters. Defaults to `null`. |
| `notes` | string \| null | Rich text notes as a sanitized HTML fragment, up to 20 000 characters. Defaults to `null`. See [Notes](#notes). |
| `categoryId` | uuid \| null | The category or subcategory the link is filed in. `null` means unsorted (the default). |
| `rating` | integer \| null | 1–5 stars. `null` means not rated (the default). |
| `createdAt` | date-time | Read-only. The time the link was added. |
| `updatedAt` | date-time | Read-only. |

```json
{
  "id": "9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02",
  "title": "Cacio e pepe, properly",
  "url": "https://www.seriouseats.com/cacio-e-pepe",
  "description": "The emulsion trick that keeps the cheese from clumping.",
  "notes": null,
  "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
  "rating": 4,
  "createdAt": "2026-11-19T12:45:00.000Z",
  "updatedAt": "2026-11-19T12:45:00.000Z"
}
```

#### Notes

`notes` holds rich text from the UI's editor: formatted text, lists and links. On create and update the server sanitizes it against an allowlist, so anything the API returns is safe to render:

- Allowed tags: `p`, `br`, `strong`, `b`, `em`, `i`, `u`, `s`, `code`, `pre`, `blockquote`, `h3`, `h4`, `ul`, `ol`, `li`, `a`, `hr`. Other tags are removed; their text is kept, except for `script`, `style` and similar, which are removed with their contents.
- The only allowed attribute is `href` on `a`, with an `http`, `https` or `mailto` URL. Any other `href` is dropped. Every link is stored with `target="_blank" rel="noopener noreferrer"`.
- Notes with no text and no links left after sanitizing (for example `<p></p>`) are stored as `null`. Send `null` to clear them.
- The 20 000-character limit applies to the sanitized HTML.

```json
{
  "notes": "<p>Related pages:</p><ul><li><a href=\"https://www.wonderfull.co/careers\" target=\"_blank\" rel=\"noopener noreferrer\">Careers</a></li><li><a href=\"https://www.wonderfull.co/about\" target=\"_blank\" rel=\"noopener noreferrer\">About</a></li></ul>"
}
```

### Create a category: `POST /api/categories`

| Body field | Required | Notes |
| --- | --- | --- |
| `name` | yes | Trimmed. Must not be empty and must be at most 80 characters. |
| `parentId` | no | Leave it out or send `null` for a top-level category. Send a category id to create a subcategory. |

```
POST http://127.0.0.1:3000/api/categories
```

Top-level category:

```sh
curl -s -X POST $BASE/api/categories \
  -H 'Content-Type: application/json' \
  -d '{ "name": "Food links" }'
```

Subcategory:

```sh
curl -s -X POST $BASE/api/categories \
  -H 'Content-Type: application/json' \
  -d '{ "name": "Thai", "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01" }'
```

**201**

```json
{
  "data": { "id": "3a7c9e21-5b4d-4f6a-8c2e-0d1f2a3b4c5d", "name": "Thai", "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01", "createdAt": "2026-11-20T18:00:00.000Z", "updatedAt": "2026-11-20T18:00:00.000Z" }
}
```

**Errors**

| Status | Code | When |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | `name` is missing, empty or too long, or `parentId` doesn't exist. |
| 409 | `DUPLICATE_CATEGORY` | The parent already has a category with that name (the check ignores case). |

```json
{
  "error": {
    "code": "DUPLICATE_CATEGORY",
    "message": "A category with this name already exists here.",
    "details": [{ "field": "name", "message": "\"Italian\" is already in Food links." }]
  }
}
```

### Update a category: `PATCH /api/categories/:id`

Renames a category, moves it under a different parent, or both. Send only the fields that change.

| Body field | Notes |
| --- | --- |
| `name` | Same rules as create. |
| `parentId` | A category id, or `null` to make the category top-level. It can't be the category itself or one of its descendants. |

```
PATCH http://127.0.0.1:3000/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e05
```

Rename:

```sh
curl -s -X PATCH $BASE/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e05 \
  -H 'Content-Type: application/json' \
  -d '{ "name": "React & Motion" }'
```

Move to top level:

```sh
curl -s -X PATCH $BASE/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e05 \
  -H 'Content-Type: application/json' \
  -d '{ "parentId": null }'
```

Move under another category:

```sh
curl -s -X PATCH $BASE/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e05 \
  -H 'Content-Type: application/json' \
  -d '{ "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e04" }'
```

**200**

```json
{
  "data": { "id": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e05", "name": "React & Motion", "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e04", "createdAt": "2026-11-05T09:31:00.000Z", "updatedAt": "2026-11-20T18:05:00.000Z" }
}
```

**Errors**

| Status | Code | When |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | The `name` is invalid, the parent doesn't exist, or the new parent is the category itself or one of its descendants. |
| 404 | `NOT_FOUND` | No category has that id. |
| 409 | `DUPLICATE_CATEGORY` | The new parent already has a category with that name. |

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Some fields need attention.",
    "details": [{ "field": "parentId", "message": "A category can't be moved inside itself." }]
  }
}
```

### Delete a category: `DELETE /api/categories/:id`

Deletes the category and all of its subcategories. Links filed anywhere in that subtree are **not** deleted. They move to the deleted category's parent, or become unsorted (`categoryId: null`) if it was a top-level category. The response lists everything the delete changed, so clients can update their caches.

```
DELETE http://127.0.0.1:3000/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01
```

```sh
curl -s -X DELETE $BASE/api/categories/6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01
```

**200**

```json
{
  "data": {
    "id": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01",
    "deletedCategoryIds": [
      "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01",
      "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
      "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e03"
    ],
    "movedLinkIds": [
      "9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02",
      "9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a03"
    ],
    "movedTo": null
  }
}
```

**404**: no category has that id.

### Create a link: `POST /api/links`

The server sets `id`, `createdAt` and `updatedAt`.

After the link is saved, the server starts generating its thumbnail in the background (see [Get a link's thumbnail](#get-a-links-thumbnail-get-apilinksidthumbnail)). The response doesn't wait for the thumbnail, and a failed thumbnail doesn't fail the create.

| Body field | Required | Notes |
| --- | --- | --- |
| `title` | yes | Trimmed. Must not be empty and must be at most 200 characters. |
| `url` | yes | An absolute `http(s)` URL of at most 2048 characters. Must not already be saved. |
| `description` | no | Up to 2000 characters. Empty or left out means `null`. |
| `notes` | no | HTML fragment, sanitized (see [Notes](#notes)); at most 20 000 characters afterwards. Empty or left out means `null`. |
| `categoryId` | no | An existing category id, or `null` / left out for unsorted. |
| `rating` | no | A whole number from 1 to 5, or `null` / left out for not rated. |

```
POST http://127.0.0.1:3000/api/links
```

All fields:

```sh
curl -s -X POST $BASE/api/links \
  -H 'Content-Type: application/json' \
  -d '{
    "title": "Pozole rojo",
    "url": "https://www.mexicoinmykitchen.com/pozole-rojo/",
    "description": "Make the chile sauce a day ahead.",
    "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e03",
    "rating": 4
  }'
```

Required fields only. The link is unsorted and not rated:

```sh
curl -s -X POST $BASE/api/links \
  -H 'Content-Type: application/json' \
  -d '{ "title": "DDIA notes", "url": "https://dataintensive.net/" }'
```

**201**

```json
{
  "data": {
    "id": "c4d5e6f7-1a2b-4c3d-8e9f-0a1b2c3d4e5f",
    "title": "Pozole rojo",
    "url": "https://www.mexicoinmykitchen.com/pozole-rojo/",
    "description": "Make the chile sauce a day ahead.",
    "notes": null,
    "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e03",
    "rating": 4,
    "createdAt": "2026-11-20T18:10:00.000Z",
    "updatedAt": "2026-11-20T18:10:00.000Z"
  }
}
```

**Errors**

| Status | Code | When |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | The title is missing or too long, the URL is invalid or too long, the description or notes are too long or not text, the category doesn't exist, or the rating is not 1–5 or `null`. |
| 409 | `DUPLICATE_URL` | A link with this URL is already saved. |

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Some fields need attention.",
    "details": [
      { "field": "url", "message": "Enter a web address that starts with http:// or https://." },

  }
}
```

    "message": "This link is already saved.",

### Import links in bulk: `POST /api/links/import`

Creates many links at once from pasted text (for example, from a text area). Every imported link is filed in the same category.

| Body field | Required | Notes |
| --- | --- | --- |
| `text` | yes | The links to import, in the format below. At most 1,000 entries and about 1 MB of text. |
| `categoryId` | yes | The category or subcategory for every imported link, or `null` to import them as unsorted. |

**Text format.** Entries are separated by one or more blank lines. In each entry, the first line is the title, the second line is the URL, and any further lines are the description (kept as separate lines). Leading and trailing spaces on each line are ignored, and both `\n` and `\r\n` line endings work.

```
link 1
http://www.somewhere.com

some other link
http://www.foo.com
this is a really great site....
```

**How entries are handled.** Each entry is created on its own, with the same rules as [Create a link](#create-a-link-post-apilinks). An entry that breaks a rule is skipped and listed in `skipped`, and the others are still created. Examples of skipped entries:

- the URL is missing or invalid
- the title or description is too long
- the URL is already saved, or appears earlier in the same text

Because duplicates are skipped, it's safe to send the same import again after a partial failure. Imported links aren't rated, and each one gets a thumbnail generated in the background, as with a single create.

```
POST http://127.0.0.1:3000/api/links/import
```

```sh
curl -s -X POST $BASE/api/links/import \
  -H 'Content-Type: application/json' \
  -d '{
    "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
    "text": "link 1\nhttp://www.somewhere.com\n\nsome other link\nhttp://www.foo.com\nthis is a really great site....\n\nbad url\nnot-a-url"
  }'
```

From a file, letting `jq` handle the JSON escaping:

```sh
jq -n --rawfile text links.txt --arg cat 6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02 \
  '{ text: $text, categoryId: $cat }' |
  curl -s -X POST $BASE/api/links/import -H 'Content-Type: application/json' -d @-
```

**201**: at least one link was created. **200**: the text was read but no link was created, so every entry is in `skipped`.

```json
{
  "data": {
    "created": [
      {
        "id": "a73fc6db-7aa8-4bec-bb72-c5f575dbacbc",
        "title": "link 1",
        "url": "http://www.somewhere.com",
        "description": null,
        "notes": null,
        "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
        "rating": null,
        "createdAt": "2026-11-21T19:20:00.000Z",
        "updatedAt": "2026-11-21T19:20:00.000Z"
      },
      {
        "id": "873872c9-275c-42aa-b8d1-5895a1a02151",
        "title": "some other link",
        "url": "http://www.foo.com",
        "description": "this is a really great site....",
        "notes": null,
        "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
        "rating": null,
        "createdAt": "2026-11-21T19:20:00.010Z",
        "updatedAt": "2026-11-21T19:20:00.010Z"
      }
    ],
    "skipped": [
      {
        "entry": 3,
        "line": 8,
        "title": "bad url",
        "url": "not-a-url",
        "code": "VALIDATION_FAILED",
        "message": "Enter a web address that starts with http:// or https://."
      }
    ]
  },
  "meta": { "total": 3, "created": 2, "skipped": 1 }
}
```

| `skipped` field | Meaning |
| --- | --- |
| `entry` | The entry's position in the text, counting from 1. |
| `line` | The line the entry starts on, counting from 1. |
| `title`, `url` | The entry's first two lines, as given. |
| `code` | `VALIDATION_FAILED` or `DUPLICATE_URL`. |
| `message` | Why the entry was skipped, ready to show to the user. |

**Errors.** These reject the whole request, and nothing is created:

| Status | Code | When |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | `text` is missing, blank or too long; there are more than 1,000 entries; `categoryId` is missing; or the category doesn't exist. |

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Some fields need attention.",
    "details": [{ "field": "categoryId", "message": "That category no longer exists. Pick another." }]
  }
}
```

A `500` or `503` part-way through stops the import. The links created before the failure are kept, so send the same request again: links already saved are skipped as duplicates.

### Get a link's thumbnail: `GET /api/links/:id/thumbnail`

Returns the link's thumbnail as a 640×360 WebP image. The image is read from the directory set by `THUMBNAIL_DIR`, which is outside the project.

The thumbnail is generated when the link is created. The server uses the page's Open Graph image (`og:image`) if it has one, and otherwise a screenshot of the page from the Microlink API. Generation usually takes a few seconds, so expect a `404` right after a create. If generation fails, the link has no thumbnail and this endpoint keeps returning `404`.

```
GET http://127.0.0.1:3000/api/links/9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02/thumbnail
```

```sh
curl -s -o thumbnail.webp -w '%{http_code} %{content_type}\n' \
  $BASE/api/links/9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02/thumbnail
```

In the UI:

```html
<img src="http://127.0.0.1:3000/api/links/9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02/thumbnail" alt="" width="640" height="360">
```

**200**: the image, with `Content-Type: image/webp`.

**404**: no link has that id (`"That item no longer exists. It may have been deleted."`), or the link has no thumbnail yet:

```json
{ "error": { "code": "NOT_FOUND", "message": "This link has no thumbnail yet." } }
```

## Export and import

Back up every category and link to one JSON file, and restore it later or on another install
(spec 004). Thumbnails aren't included; they're generated again after an import.

### File format

The file is the API's own `Category` and `Link` objects in an envelope. Notes are HTML, carried as
ordinary JSON strings.

```json
{
  "format": "link-organizer-export",
  "version": 1,
  "exportedAt": "2026-11-25T18:00:00.000Z",
  "counts": { "categories": 2, "links": 1 },
  "categories": [
    { "id": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01", "name": "Food", "parentId": null, "createdAt": "2026-11-01T10:00:00.000Z", "updatedAt": "2026-11-01T10:00:00.000Z" },
    { "id": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02", "name": "Italian", "parentId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e01", "createdAt": "2026-11-01T10:01:00.000Z", "updatedAt": "2026-11-01T10:01:00.000Z" }
  ],
  "links": [
    {
      "id": "9b2e7a10-4c3d-4e5f-8a6b-7c8d9e0f1a02",
      "title": "Wonderfull",
      "url": "https://www.wonderfull.co",
      "description": null,
      "notes": "<p>See <a href=\"https://www.wonderfull.co/careers\" target=\"_blank\" rel=\"noopener noreferrer\">Careers</a></p>",
      "categoryId": "6f1d2c4e-8a3b-4c5d-9e7f-1a2b3c4d5e02",
      "rating": 4,
      "createdAt": "2026-11-02T09:00:00.000Z",
      "updatedAt": "2026-11-02T09:00:00.000Z"
    }
  ]
}
```

- `format` and `version` identify the file; import refuses anything else.
- Categories are listed parents first; links oldest first.
- `rating` is 1–5 or `null` (not rated), as everywhere in the API.

### Export everything: `GET /api/export`

Returns the export file. The body is the file itself, not wrapped in `{ data }`, and the response
has `Content-Disposition: attachment; filename=link-organizer-backup-YYYY-MM-DD.json` (UTC date).

```sh
curl -s -OJ $BASE/api/export          # saves link-organizer-backup-2026-11-25.json
```

**200**: the file, as above.

### Import a file: `POST /api/import`

The body is an export file. The limit is 50 MB, at most 5,000 categories and 20,000 links.

```sh
curl -s -X POST $BASE/api/import -H 'Content-Type: application/json' \
  --data-binary @link-organizer-backup-2026-11-25.json
```

Import **merges and never overwrites**: nothing already in the database is changed or deleted.
Into an empty database it's a full restore, with the same ids, hierarchy, notes, ratings and timestamps.

Categories, parents first:

- A category whose `id` already exists is used as it is (`existing`); it isn't renamed or moved.
- Otherwise, one with the same name (case-insensitive) under the same parent is reused (`merged`):
  the file's subcategories and links go into it.
- Otherwise it's created with the file's `id`, `name` and timestamps.
- A `parentId` that's in neither the file nor the database, or that forms a cycle, makes the category top-level.
- An entry with an invalid id or name is skipped; its subcategories become top-level and its links unsorted.

Links, in file order:

- A URL that's already saved, or repeated earlier in the file, is skipped with `DUPLICATE_URL`.
- The same rules as [creating a link](#create-a-link-post-apilinks) apply; notes are sanitized. A link
  that breaks one is skipped with `VALIDATION_FAILED`.
- The link keeps its `id` unless that id is already taken, in which case it gets a new one.
- `categoryId` follows the categories above; an unknown category makes the link unsorted.
- `createdAt` and `updatedAt` are kept when they're valid ISO timestamps.
- A thumbnail is generated in the background, unless one for that id is already on disk.

Each item is saved on its own, so importing the same file twice creates nothing the second time,
and a retry after a `500` or `503` part-way through is safe.

**201** (something was created) or **200** (nothing was):

```json
{
  "data": {
    "categories": { "created": 1, "existing": 0, "merged": 1, "skipped": [] },
    "links": {
      "created": 0,
      "skipped": [
        { "index": 1, "title": "Wonderfull", "url": "https://www.wonderfull.co", "code": "DUPLICATE_URL", "message": "Already saved as \"Wonderfull\"." }
      ]
    }
  },
  "meta": { "categories": 2, "links": 1 }
}
```

Skipped categories are `{ index, name, code, message }`. `index` is the 1-based position in the file's
`categories` or `links` array; `meta` counts the entries in the file.

**400**: the body isn't an export file. Nothing is written.

```json
{ "error": { "code": "VALIDATION_FAILED", "message": "Some fields need attention.", "details": [{ "field": "format", "message": "This isn't a Link Organizer export file." }] } }
```

| `field` | When |
| --- | --- |
| `format` | `format` isn't `"link-organizer-export"` (or the body isn't an object) |
| `version` | `version` isn't `1` |
| `categories`, `links` | not an array, or more than 5,000 categories / 20,000 links |
| `body` | malformed JSON, or more than 50 MB |

## Errors

Every response with a status other than 2xx uses the same body:

```json
{ "error": { "code": "NOT_FOUND", "message": "That item no longer exists. It may have been deleted." } }
```

| Status | Code | Message | Notes |
| --- | --- | --- | --- |
| 400 | `VALIDATION_FAILED` | Some fields need attention. | `details` lists `{ field, message }` for each problem. Malformed JSON reports `field: "body"`. |
| 404 | `NOT_FOUND` | That item no longer exists. It may have been deleted. | Returned for an unknown id, an id that is not a UUID, and an unknown route. |
| 409 | `DUPLICATE_URL` | This link is already saved. | |
| 409 | `DUPLICATE_CATEGORY` | A category with this name already exists here. | |
| 500 | `INTERNAL_ERROR` | Something went wrong on the server. Try again. | Transient; the client can retry. |
| 503 | `SERVICE_UNAVAILABLE` | The server is unavailable right now. Try again in a moment. | The database can't be reached. Transient. |

Examples:

```sh
# 404: the id is not a UUID
curl -s $BASE/api/links/not-a-uuid

# 400: malformed JSON
curl -s -X POST $BASE/api/links -H 'Content-Type: application/json' -d '{bad json'
```
